# Postmortem: more traditional styles and borders (2026-10-15)

## Request
Add more patterns to the traditional editor's Classics tab and to what the AI can choose.

## What was added
Five new styles (10 in total), all generated by knot rules in `lib/normal.ts`:
- **Double chevron**: two chevrons side by side (strings a multiple of 4, 12 suggested).
- **Criss-cross**: two zigzags facing each other, making X's with diamonds between (3 colours max, 12 suggested).
- **Lightning**: a zigzag with one long and one short leg.
- **Checkerboard** and **Ripple**: strings never move (only fb/bf knots); odd rows choose which neighbour shows.

A **border** option works with every style: the edge strings stay put (fb on the left, bf on the right) and the
inner pattern is shifted by one row so its knots line up with the other row parity. Classics has an
"Add a border" switch (selected colour); the AI recipe gained a `border` field.

## How styles were chosen
Prototyped about a dozen rules and compared worn previews, clean-repeat length and colour balance. Dropped:
three "fishbone" variants (looked identical to the chevron) and a small "ripple" zigzag (looked like a
narrow zigzag). Kept only styles that read clearly differently.

## Design changes
- `STYLE_INFO` now has a colour `layout` (mirrored / blocks / double / pairs), `minStrings` and `maxColors`
  instead of a `mirrored` flag; `RULES` holds each style's knot rule, phases and repeat cycle.
- New helpers: `colorRoom`, `fitStrings`, `suggestedStrings`, `withBorder`, shared `FLIP_KNOT`.
- Recipe: border detection in the offline parser ("a black border", "border in gold", "white edges");
  a colour named only for the border is kept out of the palette. Small models add borders nobody asked
  for, so the server only keeps a border the prompt mentions, and drops the border colour from the palette
  unless the person named it for the pattern too.

## Issues hit
- Serena's whole-file regex (`\A.*\Z`) was rejected as ambiguous; anchored the pattern to the first and
  last lines instead.
- The repeat caption under narrow diagrams was clipped; shortened it to "✓ Repeats cleanly" with the full
  explanation on hover. Long bordered titles overflowed the name box, so names no longer include the border.

## Verification
- Every style × 6 string counts × with/without border: all 120 builds repeat cleanly.
- Live AI (llama3.2:3b), 10 prompts: correct style every time, ~0.5 s; borders only when asked.
- Headless browser: Classics with/without border, loading a bordered criss-cross, AI lightning example;
  no console errors. lint, tsc, build clean; semgrep 0 findings.

## Note
In zigzag-family styles some strings only ever get knotted over, so the strings that show tie most of the
knots and the cut list makes them much longer (about 1.1 m each for a 16 cm, 8-string lightning).
That follows from the knot model, but is worth checking against a real bracelet.
